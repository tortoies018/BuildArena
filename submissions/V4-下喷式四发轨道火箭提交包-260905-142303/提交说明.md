## 提交流程

1. Kaggle 赛道选择 `Build with Agent / Copilot`。
2. 按页面要求上传六个官方文件；若页面接受压缩包，则使用“官方六文件”ZIP。
3. 依据 `kaggle_submission_fields.md` 填写 Title、Subtitle、Track、Cover Image、Project Description 和 Media Gallery。
4. 在 Writeup 区粘贴 `kaggle_writeup.md`，视频字段使用上面的 GitHub 公开视频链接。
5. 不要把 `提交说明.md`、字段清单、Writeup、图片、`SHA256SUMS.txt` 或录像误当成六个必交文件之一。
6. 提交后以官方评分器结果为准，再把正式成绩和圈数补入仓库记录。
