# S01 轨道火箭 Orbital Lancer V2：设计与学习总结

> **版本状态：已淘汰。** V2 已经沿工具 `+Z` 竖直，但实机截图确认四台 Booster 被装在整根箭体的最上端，因此上下关系仍然颠倒。正确判断必须同时检查推力方向与发动机的物理位置。本版保留为失败样本，正式候选改为底置发动机的 V3。

## 本版修正

A1 的实机截图表明，建造工具里的北向 `+Y` 在游戏中是水平方向，不是火箭竖直轴。V2 重新创建独立 MCP 生命周期，明确使用工具坐标 `+Z` 作为游戏竖直方向；两只大油箱中心依次位于 `[0, 0, 2]` 和 `[0, 0, 5]`，四台主推进器位于 `z = 7`，推进方向均由工具确认是“straight up”。

本版没有修改或覆盖 A1。A1 保留为错误样本，V2 是新的 Autopilot 原始构建。

## 赛项定位

- 赛项：BuildArena 2.0 Construction Challenge，Season 01 “Stable Orbital”。
- 路线与模式：`Build with Agent / Autopilot`。
- 原始机器名：`S01_Autopilot_Orbital_Lancer_V2_260904_212909`。
- 原始结构在 MCP 构建结束后立即保存并关闭；随后只在副本中调整合法的非几何控制 `Data`。

## 结构总览

V2 共 39 块，比 A1 的 17 块增加了双油箱、四向发射支架、成对姿态控制器、RCS 和三段冗余拉撑。

| 子系统 | 数量 | 作用 |
| --- | ---: | --- |
| Starting Block | 1 | 位于发射架中心，是轨迹跟踪目标与全船结构根节点。 |
| Fuel Barrel Big | 2 | 竖直串联，提供 200 单位主燃料。 |
| Booster | 4 | 顶部四角完全对称，合力沿工具 `+Z` 竖直向上。 |
| Reaction Steering Block | 6 | 三个正交轴各一对，提供成对、冗余的姿态控制。 |
| Steering Thruster | 4 | 上部东西侧与下部南北侧成对布置，提供细调和自动制动。 |
| Double Wooden Block | 4 | 从 Starting Block 向东、西、南、北展开四条发射支腿。 |
| Single Wooden Block | 2 | 延长东西支腿，承载竖直轴反作用轮。 |
| Grip Pad | 4 | 四点接地，降低七格高火箭在点火前倾倒的概率。 |
| Brace | 12 | 分别加固发射架—下油箱、两油箱级间、发动机—上油箱。 |

四台助推器名义总推力约等于正常重力下 96 个质量单位。两只大油箱提供 200 单位主燃料，四台 Booster 另各带 1 单位内部燃料，名义总量为 204。两只油箱通过可供油端面直接连接，不增加外置燃料管。

## 受力路径

1. Starting Block 顶面连接下油箱，四条水平支腿同时通过四根斜拉杆连接下油箱低位，形成五条根部受力路径。
2. 两只大油箱除中心端面连接外，东、西、南、北各有一根纵向拉杆跨接级间。
3. 四台 Booster 各有独立斜拉杆连接上油箱肩部，避免主推力全部集中在四个端面安装点。
4. 姿态控制器全部左右或南北成对布置；燃料消耗后质量中心沿竖直轴变化，不形成固定侧向偏载。
5. 本版没有分离器。所有 39 个原始跟踪块都应在飞行结束时继续连接 Starting Block，以保护结构完整性分。

## 控制方案

调参副本只写入按键、控制模式、反作用轮速度与阻尼，方块数量、GUID、位置、旋转、缩放和连接端点均与原始 BSG 相同。

| 按键 | 功能 | 参与部件 |
| --- | --- | --- |
| `↑` | 启动四台主推进器 | 4 × Booster |
| `↓` | 关闭四台主推进器 | 4 × Booster |
| `← / →` | 绕火箭纵轴左 / 右转 | 2 × 竖直轴反作用轮 + 2 × 上部 RCS |
| 小键盘 `8 / 2` | 向前 / 向后俯仰 | 2 × 东西轴反作用轮 + 2 × 下部 RCS |
| 小键盘 `4 / 6` | 向左 / 向右侧倾 | 2 × 南北轴反作用轮 |

所有反作用轮与 RCS 均启用自动制动。相对安装在轴线两侧的控制块使用交换后的左右键，使同一次按键产生同向转矩，而不是互相抵消。

## 使用流程

1. 加载文件名带 `_tuned` 的调参版，确认 Num Lock 已开启。
2. 进入模拟后先不要点火，依次短按 `←/→`、小键盘 `8/2`、小键盘 `4/6`，确认三个控制轴都能回正且没有结构脱落。
3. 按一次 `↑` 启动四台主推进器；火箭离开地面后按 `↓` 关机，确认四条支腿没有把机体卡在地面。
4. 用小键盘 `8/2` 把竖直上升逐渐转为轨道切向飞行；`←/→` 修正航向，小键盘 `4/6` 修正侧倾。
5. 速度接近稳定绕行所需值时关掉主推进，只使用短促姿态修正。不要持续径向爬升。
6. 先完成连续三圈，再尝试缩短用时。飞行结束前不得分离或删除任何部件。

详细操作与故障排查见同版本目录中的 `使用说明.md`。

## 静态验收结果

- 原始版和调参版均能作为 XML 正常解析。
- 两版均为 39 个方块，方块 ID、GUID、位置、旋转、缩放完全一致。
- 调参版只修改 4 台 Booster、6 个 Reaction Steering Block 和 4 个 Steering Thruster 的 `Data`。
- 原始有效记录包含 39 次有效结构操作；没有失败或回滚的结构操作。
- Tracker 保持启用，目标仍是 Starting Block，采样率保持 `10 Hz`。

## 尚待实机验收

- 火箭是否以竖直姿态出现在游戏中，四个 Grip Pad 是否同时接地。
- 四台 Booster 是否同步启动、同步关闭，并且实际加速度方向向上。
- 三组控制方向是否与说明一致；若某一组左右相反，只能交换该组合法按键字段，不能旋转或移动方块。
- 两级油箱是否能连续向四台主推进器供油。
- 最大推力、急转和三圈飞行后，39 个原始块是否仍与 Starting Block 连通。
- 生成 Tracker 轨迹 CSV，并以连续三圈和更短有效飞行时间为调参目标。

## 本版得到的结论

1. BuildArena 工具的 `+Z` 才是本场景中应采用的竖直建造轴；不能从“North”或屏幕朝向推断游戏高度。
2. 高火箭不能只依靠中心 Starting Block 接地。四向支腿和 Grip Pad 把静态支撑范围扩展到 `x/y = ±2`，更适合点火前保持直立。
3. 成对反作用轮必须同时考虑安装轴方向和按键方向。位于相反法向的两个轮子若使用完全相同映射，可能互相抵消，因此 V2 对相反轴的按键进行了交换。
4. RCS 不替代反作用轮：反作用轮负责主要姿态转矩，RCS 负责快速细调和制动，二者共同使用相同的驾驶键。
5. 调参副本必须与 MCP 原始版严格同构。任何结构问题都应另建 V3，而不是在 V2 tuned 文件中手工改几何。
