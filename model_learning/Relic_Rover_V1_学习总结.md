# 远程鱼叉拖车 V1：学习总结

## 本版暴露的问题

1. 转向不能只检查按键是否能驱动关节，还必须检查整根车轴转动时是否会与底盘、车轮或其他部件发生干涉。单个转向块同时承受车重、轮胎侧向摩擦和转向扭矩时，很容易断裂并引起连锁解体。
2. 只具备移动能力不等于具备拖拽能力。车身过轻会在鱼叉收绳时被目标反向拖动或掀翻；增加重量时还必须同步增加车轮数量、驱动力和接地面积。
3. 固定朝向的鱼叉无法可靠命中远处目标。面对会冻结近距离机械的目标，瞄准必须能够在安全距离独立调整，不能依靠反复转动车身完成精确对准。
4. 起始核心方块不应被当成需要抛弃的附件。核心必须保留在几何中心和主要受力路径中，周围结构以它为中心对称展开。

## 下一版必须检查

- 满载转向时活动部件的运动包络和碰撞干涉。
- 收绳时车辆是否后滑、侧翻或发生结构偏载。
- 瞄准机构是否独立于底盘转向。
- 核心是否被保留并成为主结构的一部分。
