# 控制习惯与结构验收规范

## 火箭坐标与上下验收

- BuildArena 建造工具中，游戏竖直上方使用 `+Z`；`+Y` 是水平方向。
- 验收火箭不能只看“是否竖直”，还要看鼻锥、油箱、发动机和支脚的相对高度：鼻锥在最高处，发动机与支脚在最低区域。
- Booster 的工具朝向文字不能单独证明实际推进方向。V3 实机截图表明，工具返回 `straight up` 时可见喷焰也朝上，反作用力实际朝下。最终必须短点火确认：喷焰朝下且箭体上升；工具文字、安装位置和实机运动有冲突时，以实机证据为准。
- 火箭主推统一使用 `↑` 启动、`↓` 关闭；`←/→` 用于偏航，小键盘 `8/2` 用于俯仰，小键盘 `4/6` 用于侧倾。

## 固定控制规则

- 车辆移动：方向键上、下、左、右。
- 角度控制：数字小键盘 `8` 向上、`2` 向下、`4` 向左、`6` 向右，必须保持空间对称。
- 发射与释放等攻击开关：数字小键盘 `1` 和 `0`；默认小键盘 `1` 发射或启动，小键盘 `0` 释放或关闭。禁止再映射为主键盘数字键。
- 不得在新模型中把车辆移动重新映射到数字小键盘，也不得用不对称的字母键控制炮塔角度。

## 转向验收

1. 不能只确认转向键已经写入；必须确认结构能够实际产生偏航力矩。
2. 固定轮重车优先使用左右差速，必要时加入不承重的惯性辅助；不能再次依赖一个承载整根车轴的脆弱转向关节。
3. 必须分别测试静止原地转向、前进中转向、倒车中转向和拖拽负载时转向。
4. 转向轮或活动关节的运动包络不能扫入车架、相邻车轮或加固件。

## 强度验收

1. 结构强度来自多条独立受力路径、左右对称连接、三角支撑和足够的横向抗扭连接，不等同于增加配重。
2. 车轮必须分别拥有自己的挂载点；一个连接断裂不能让整排车轮同时脱落。
3. 进入模拟、落地、急转和满速收绳都必须检查是否出现连锁解体。
4. 静态碰撞检查通过后仍需进行动态物理测试。
