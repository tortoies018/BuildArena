# 核心重型遗迹拖车 V3：学习总结

## 已确认的设计结论

1. 静态碰撞检查通过，不等于机器能承受进入模拟时的冲击。设计阶段必须同时检查机器最低点、车轮半径、保存文件中的全局出生高度，以及落地时动态关节所承受的瞬时载荷。

2. 车辆不应依靠单个转向块承担整根前轴、两个车轮和车身的转向载荷。重车转向时，这种结构会同时承受扭矩、侧向摩擦和碰撞干涉，容易导致关节断裂并引发连锁解体。固定轮轴配合无外部活动结构的惯性转向，更适合本关的重型拖拽车辆。

3. 转向结构必须在设计时逐项检查：能否产生足够的转向力、转动部件是否会扫入车架或车轮、关节是否承担了不必要的车重、松开按键后是否能制动，以及满载拖拽时能否保持方向。

4. 起始核心方块应放在几何中心和受力中心，主要结构从核心向前、后、左、右对称展开。核心不应作为准备丢弃的底部附件，也不应通过单一弱连接承受整车重量。

5. 对称布局不仅是外观要求，也能减少偏航、落地侧翻和鱼叉回收时的偏载。车轮、配重、转向器、鱼叉以及加固件均应成对布置；需要例外时必须记录原因。

6. 增加重量必须同时增加接地面积和驱动力。只增加配重会让车辆更难启动；只提高轮速则可能导致打滑和关节冲击。重型拖车应使用多轮驱动、低重心配重和足够的自动制动。

7. 瞄准机构必须与车辆转向分离。车辆负责移动到安全射击位置，炮塔负责水平微调和俯仰微调；两套控制不能占用相同按键，也不能让瞄准关节承担底盘载荷。

8. 双鱼叉必须保持镜像安装、朝向一致、俯仰同步。否则两根绳索会向相反方向施力，使目标旋转、脱钩或把炮塔扯坏。

9. 本条已被用户后续规则再次替代：车辆移动统一使用方向键；数字小键盘的 `8/2/4/6` 保留给角度控制，并按上、下、左、右的空间关系对称设置；攻击、发射和释放使用数字小键盘 `1/0`，不能使用主键盘数字键。

10. 本关的验收不能只看机器是否能移动。必须依次验证：进入模拟不解体、前后移动、原地和行进转向、炮塔水平与俯仰无干涉、鱼叉命中、满速收绳不掀翻底盘，以及车身保持在遗迹冻结范围外。

## 本版仍需通过实机验证的项目

- 数字小键盘键名在当前 Besiege 版本中是否按预期载入，并确认 Num Lock 状态不会影响输入。
- 双惯性转向在最大配重下的转向速度是否合适；过快时降低转向速度，过慢时再提高，而不是增加脆弱的机械转向轴。
- 双鱼叉同时命中遗迹后是否产生不必要的旋转；若发生，应改为分离发射键或缩小两根鱼叉之间的距离。
- 冻结范围边缘的实际安全射击距离，以及炮塔俯仰限制是否覆盖目标高度。

## 后续模型的固定检查表

- 核心是否位于几何中心并保留在机器上。
- 结构、质量、动力和控制是否左右对称。
- 出生高度是否让车轮接近地面，而不是让机器自由坠落。
- 所有活动部件的运动包络是否与车架、车轮和其他活动部件相交。
- 转向是否在空载和拖拽状态下都能完成，且不会把载荷集中到单个关节。
- 控制键是否符合用户约定，并在交付说明中明确列出。
- MCP 的几何总结、保存文件参数和关卡内动态测试是否分别通过。
