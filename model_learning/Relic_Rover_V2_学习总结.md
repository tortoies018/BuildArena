# 重型瞄准拖车 V2：学习总结

## 本版暴露的问题

1. 静态结构通过检查不代表进入模拟后不会解体。保存文件的全局出生高度、最低部件高度和车轮半径必须一起检查；让重型机械从高处掉落，会把瞬时冲击集中到关节和连接点上。
2. 增加配重后，落地冲击会被同步放大。重型设计必须优先做到接近地面出生、低重心和多点支撑，不能依靠继续增加连接件来掩盖错误的出生条件。
3. 模型即使包含起始方块，如果它位于主车架之外或通过可分离结构连接，仍然不能称为“中心核心”。核心必须同时满足几何居中、结构保留和处于主要受力路径三个条件。
4. 瞄准关节只应承担炮塔和武器载荷，不能参与承载底盘。左右武器需要镜像安装、方向一致，并在实际俯仰范围内检查是否扫入车架。
5. 转向系统必须避免脆弱的承重活动车轴。对重型拖车，可以优先考虑固定轮轴配合惯性转向，以减少外露机械关节受到的复合载荷。

## 下一版必须检查

- 进入模拟瞬间是否存在可见下落以及动态冲击。
- 核心是否位于原点并被左右、前后结构对称包围。
- 重量、轮数、驱动力和制动力是否成比例增加。
- 炮塔水平与俯仰运动是否和底盘完全解耦。
- 车辆移动是否使用方向键；角度控制是否遵守数字小键盘 `8/2/4/6` 的空间对称关系；攻击、发射和释放是否使用数字小键盘 `1/0`，并确认没有误用主键盘数字键。
