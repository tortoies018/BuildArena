# 强化差速遗迹拖车 V4：学习总结

## 本版得到的设计结论

1. 固定轮重型车辆不能只依赖惯性转向器。高抓地轮胎和高质量底盘会抵消较弱的偏航力；转向结构本身必须让左右轮组产生不同方向的驱动力，形成确定的差速转向力矩。
2. 当单个轮子只能设置一组前进和后退按键时，可以让轮组分工：中间轮组负责前后行驶，前后外侧轮组负责左右反向差速。这样同时按住前进和转向键时，车辆仍能形成行进中的转弯力矩。
3. 惯性转向器适合作为差速系统的辅助，不应该成为唯一转向来源，也不应该承担车轮、车轴或底盘重量。
4. 强度问题不能靠继续加重解决。重型底盘应从中心核心向前后形成连续脊梁，每个车轮使用独立横向挂载点，再用横向、纵向和三角拉杆组成多条受力路径。
5. 车轮半径会侵入相邻侧梁。即使重叠量只有 `0.0029`，也必须删除干涉侧梁，否则进入模拟后可能产生弹开、抖动或连锁解体。
6. 对称不仅包括部件数量，也包括受力路径。左右两侧的轮距、挂载点、配重、拉杆端点和炮塔负载都必须镜像。
7. V4 把发射和释放错误地设成了主键盘 `1/0`。最新固定规则是：方向键控制车辆移动；数字小键盘 `8/2/4/6` 控制炮塔上、下、左、右；数字小键盘 `1` 发射并收绳，数字小键盘 `0` 释放。
8. 封面只能使用该模型在 Besiege 中的真实画面，不使用图像生成、概念图、其他版本截图或占位图。

## 本版实机验证结论

- 进入模拟后车辆正常落地，底盘、八个车轮、中心核心和双鱼叉炮塔保持完整，解决了旧版落地即碎的问题。
- 短按向上方向键后车辆稳定前进，主驱动轮组生效。
- 短按向右方向键后车体航向明显改变，差速轮组与惯性辅助能够完成转向；转向过程中底盘和炮塔没有自毁。
- 双鱼叉及其炮塔在行驶和转向后仍保持连接，说明炮塔载荷没有破坏中心结构。
- 游戏键位面板显示鱼叉为主键盘 `1` 发射、`0` 分离；这正是 V4 的控制错误，后续版本必须改为数字小键盘 `1/0`。
- 这次验证证明“能落地、能前进、能右转且不解体”；满载拖动遗迹、连续急转和高速收绳仍需作为下一轮耐久测试，不能仅凭一次短距离试车判定全部通过。
