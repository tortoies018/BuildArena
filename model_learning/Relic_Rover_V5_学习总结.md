# 十二轮重型遗迹牵引车 V5：学习总结

## 本版得到的设计结论

1. `Alpha1/Alpha0` 表示主键盘数字键，`Keypad1/Keypad0` 才表示数字小键盘。只看界面中的“1/0”容易忽略两套数字键的区别，因此以后必须同时检查 BSG 内部键名和游戏内实际按键。
2. 鱼叉命中并不等于能够拖回目标。牵引能力由收绳力、整车质量、驱动轮数量、轮胎抓地和底盘受力路径共同决定；只提高鱼叉射出速度不能解决车辆被目标反向拖走的问题。
3. 提高牵引车质量时，应优先沿底盘纵向在低位延长配重，而不是把配重堆到炮塔附近。这样既能增加锚定能力，也能避免重心升高后急转侧翻。
4. 对重型固定轮底盘，驱动轮和差速转向轮需要分工。增加持续驱动轮能提高直线牵引力，但仍要保留独立反向轮组产生转向力矩，否则更重的车辆反而更难转弯。
5. 长底盘的新增车轴不能只靠接触连接。每个延长段都需要横向闭合、左右三角支撑和前后纵向连接，使鱼叉拉力能够沿多条路径传回中心核心。
6. 拖运遗迹时不应只依靠自动收绳：鱼叉命中后持续按住小键盘 `1` 收紧绳索，同时用方向键让车辆主动远离遗迹；接近目标点后再用小键盘 `0` 释放。
7. 本版把总配重从 `28.5` 提高到 `44.5`，把持续驱动轮从 4 个增加到 8 个，并把惯性转向辅助器从 2 个增加到 4 个。鱼叉收绳速度的合法上限经游戏程序集核对为 `1.5`，因此保持上限值，不能用越界参数伪造拉力。

## 固定控制规则

- `↑ / ↓`：前进、后退。
- `← / →`：差速左转、右转。
- 数字小键盘 `4 / 6`：炮塔左转、右转。
- 数字小键盘 `8 / 2`：炮塔上抬、下压。
- 数字小键盘 `1`：双鱼叉发射并持续收绳。
- 数字小键盘 `0`：释放鱼叉。

## 本版必须完成的动态验收

- 落地后十二个车轮、延长底盘、中心核心和炮塔不得脱落。
- 前进和后退时八个驱动轮应共同输出，不得出现左右侧互相抵消。
- 原地左右转以及行进中转弯都必须成功，新增质量不能让转向失效。
- 双鱼叉命中遗迹后，车辆不得被遗迹拖回或发生底盘弯折。
- 持续收绳并后退时，遗迹必须产生可观察位移；随后车辆必须能够把它拖向关卡目标区域。
- 满载急转、连续倒车和高速收绳后，新增拉杆不得发生连锁断裂。
