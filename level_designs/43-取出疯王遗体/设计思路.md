# 第 43 关“取出疯王遗体”设计思路

## 关卡判断

当前关卡是巨龙头骨场景。目标不是继续拖动上一关的遗迹方块，而是破开头骨入口附近的牙齿，进入头骨内部取得疯王遗体，再把遗体送到关卡指定标记区域。

因此，上一关的重型长车和双鱼叉不应直接沿用：长底盘不利于进入狭窄头骨，双鱼叉共用一个发射键时，只要一根偏离目标并钉入地面，整车就会被错误锚定。

## 双鱼叉失败得到的结论

1. 多个捕获器共用同一个发射键时，系统成功条件不是“至少一个命中”，而是“所有发射物都不能形成错误约束”。捕获器越多，误命中地面的概率越高。
2. 如果多个捕获器不能独立瞄准、独立发射、独立释放，就不应为了表面上的拉力简单并联。
3. 面对单个小型目标，优先使用一个位于车辆中心线上的捕获器；额外可靠性应来自导向舱、护栏和更大的有效吸取范围，而不是增加同步发射物。

## 首版方案：单吸盘破齿回收车

### 1. 车体尺度

- 使用低矮、短轴距的对称底盘，宽度控制在能够穿过龙口的范围内。
- 起始核心方块固定在底盘几何中心和主要受力路径交点。
- 配重集中在底盘低位，不把重量堆到工具臂顶部。

### 2. 破齿结构

- 车头左右使用静态装甲撞角或犁形结构，中央保留一条开放通道。
- 依靠整车驱动力撞断入口右侧牙齿，不使用会遮挡吸取器的多组旋转武器。
- 撞角的反作用力必须通过左右纵梁和三角拉杆传回中心核心，不能只挂在单个前端方块上。

### 3. 单点捕获结构

- 只使用一个中心真空吸取器，不使用双鱼叉，也不使用两个同步捕获器。
- 吸取器安装在车头中央的短工具臂上，后方设置 U 形回收舱；遗体被吸近后由侧壁和底板承托，避免完全依靠吸力悬挂。
- 工具臂只负责小范围对准，不承担整车或遗体的主要重量。

### 4. 行驶与转向

- 方向键负责车辆前进、后退、左转和右转。
- 使用多轮驱动提高破齿和载荷撤离时的牵引力；转向仍保留独立差速轮组与惯性辅助。
- 车轮挂载点左右镜像，并用横向、纵向和斜向拉杆形成多条受力路径。

### 5. 固定控制布局

- `↑ / ↓`：前进、后退。
- `← / →`：左转、右转。
- 数字小键盘 `4 / 6`：捕获头向左、向右微调。
- 数字小键盘 `8 / 2`：捕获头上抬、下压。
- 数字小键盘 `1`：启动真空吸取。
- 数字小键盘 `0`：停止吸取或释放遗体。
- 攻击、捕获和释放不得映射到主键盘数字键。

## V1 落地修订

- 固定犁铲直接装在底盘高度时会低于车轮接地面；抬高后又与中央吸盘的实体包络相切，形成遮挡。因此 V1 改成左右镜像的被动尖锥破齿，中央吸力通道保持完全开放。
- V1 的吸盘固定在中心线上，不设置活动瞄准关节。实际瞄准由整车前后移动和转向完成，所以数字小键盘 `4/6/8/2` 在本版不占用，避免为了“可动”引入脆弱关节。
- 八个动力轮统一用 `↑/↓`，优先保证直线冲齿与带载倒车的全部牵引力；`←/→` 交给前后两只竖轴反作用转向块。满载原地转向能力仍必须进入物理模拟验证。
- 真空吸盘采用数字小键盘 `1` 的按住工作模式，松开即停止吸取。V1 不使用锁定式开关，避免误触后持续吸住场景物体；数字小键盘 `0` 因该方块没有独立“关闭”映射而保留不用。
- 四条轮轴位于前后 `±1` 与 `±3`。相邻轴只隔 1 格时，太空轮会产生 `-0.0029` 的实际碰撞穿插；改为 2 格中心距后八轮均可无碰撞安装。

## 操作流程

1. 用右侧撞角对准龙口右侧牙齿，以直线短冲撞开入口。
2. 降低速度进入头骨，让中央回收舱对准遗体。
3. V1 不设置活动瞄准关节；用方向键让整车中央吸盘对准遗体，按住数字小键盘 `1` 吸取。
4. 遗体进入 U 形回收舱后保持吸取，使用方向键倒车离开头骨。
5. 转向驶向标记区域；进入目标范围后松开数字小键盘 `1` 停止吸取并释放。V1 的吸盘没有独立关闭映射，因此数字小键盘 `0` 保留不用。

## 建模前验收条件

- 车辆静态包络能够通过龙口，而不是进入后卡住车轮或炮塔。
- 只存在一个主动捕获点，不会出现第二根鱼叉误钉地面的问题。
- 撞断牙齿时车头不会向后折叠，中心核心不会脱离底盘。
- 捕获遗体后车辆能够倒车、转弯并承受偏载。
- 遗体应落入承托舱，不能全程只靠绳索或吸力悬挂。
- 模型完成后必须在本关依次验证：破齿、进龙口、吸取、倒车脱离、满载转向、目标区释放。
