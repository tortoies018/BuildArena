# V3 底置四发轨道火箭使用说明

> **已淘汰：发动机方向错误。** 用户的实机截图显示 V3 的四股火焰向上喷，反作用力实际朝下。V3 只用于失败追溯；正式测试请使用 V4 下喷式版本。

## 加载文件

日常驾驶与赛道测试加载：`V3-底置四发轨道火箭-260905-124510.bsg`

`V3-底置四发轨道火箭原始结构-260905-124510.bsg` 是 MCP 刚封存的几何证明，控制 `Data` 为空，只用于结构追溯，不作为日常驾驶文件。

## 正确上下方向

- 工具坐标 `+Z` 是游戏中的竖直上方。
- 四个 Grip Pad 位于最低处，工具高度约 `z=-0.75`。
- 四台 Booster 位于箭体底部外伸吊舱，工具高度约 `z=1`，工具已逐台确认推力朝 `+Z` 正上方。
- 双大油箱位于 `z=2` 和 `z=5`，鼻杆与圆头位于最上方 `z=7` 和 `z=7.88`。

因此，看到圆形鼻头在上、四个发动机吊舱和支脚在下才是正确姿态。V2 虽然已经竖直，但推进器装在最上端，视觉上下颠倒；不要继续用 V2 做正式测试。

## 键盘控制

| 按键 | 操作 |
| --- | --- |
| `↑` | 同步启动四台主 Booster；采用开关模式，按一次即可持续工作 |
| `↓` | 同步关闭四台主 Booster |
| `← / →` | 绕火箭竖直纵轴向左 / 向右修正 |
| 小键盘 `8 / 2` | 向前 / 向后俯仰 |
| 小键盘 `4 / 6` | 向左 / 向右侧倾 |

使用数字小键盘前请确认 Num Lock 已开启。六个反作用轮和四个 RCS 均开启自动制动；松开姿态键后应主动抑制继续旋转。

## 起飞前检查

1. 确认加载的是不带“原始结构”字样的主 `.bsg`。
2. 确认四个支脚在下、圆头在上，四台 Booster 位于下部东、西、南、北四个吊舱。
3. 不点火，分别短按 `←/→`、小键盘 `8/2`、小键盘 `4/6`。每一对键应产生相反方向的响应。
4. 若某一对方向与表格相反，只在主文件副本中交换该组的 `bmt-left` / `bmt-right` 键值；不要移动或旋转方块。
5. 按 `↑` 做极短点火，确认四台发动机同步工作、整体向上，随后立刻按 `↓` 关机。

## 起飞与入轨

1. 按一次 `↑` 垂直离地，离开发射面后按 `↓` 关机。
2. 用小键盘 `8/2` 逐步把箭体从径向上升转为沿行星表面的切向方向。
3. `←/→` 修正航向，小键盘 `4/6` 消除侧倾；全部采用短按，避免高火箭过度旋转。
4. 对准切向后再次按 `↑` 加速，接近持续绕行速度时按 `↓` 关机滑行。
5. 先以连续三圈为目标，再缩短加速时间；不要持续径向爬升，也不要主动分离任何结构。

## 常见故障

- `↑` 无反应：确认加载的是主文件，并检查四台 Booster 的 `bmt-boost` 是否为 `UpArrow`。
- 火箭向下或顶端喷射：说明加载了 V2 或错误副本；V3 的四台 Booster 必须在底部且工具确认推力为 `straight up`。
- 持续自旋：按 `↓` 关主推，松开姿态键等待自动制动，再短按反向键消除剩余角速度。
- 某轴相反：只交换该轴成对控制器的键值，不改变几何。
- 单台发动机熄火：检查对应小油箱至下部大油箱的 Fuel Line，以及吊舱是否仍连接 Starting Block。
- 起飞解体：检查 12 根 Brace 是否完整；不得在原始结构副本上补块，应创建下一几何版本。
