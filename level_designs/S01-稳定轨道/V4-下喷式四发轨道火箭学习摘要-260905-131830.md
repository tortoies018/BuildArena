# V4 下喷式四发轨道火箭学习摘要

用户提供的 V3 实机截图显示四股火焰向上喷。火箭的有效推力方向与喷焰相反，因此 V3 实际会被向下压；MCP 返回的 `Thrust ... straight up` 在本部件上与实机喷口表现冲突，不能再单独作为发动机验收依据。

V4 把四个小燃料舱通过 Single Wooden Block 支座升到工具高度 `z=1`，Booster 改挂在燃料舱底面，中心位于 `z=0`，工具返回 `straight down`，对应预期的喷焰朝下。Grip Pad 中心仍为 `z=-0.75`，低于发动机本体，为倒装后的喷口保留落地间隙。

V4 共 51 块：V3 的主要系统保持不变，新增四个发动机舱升高支座。原始版与主版均为 51 块，身份与 Transform 差异为 0，仅 14 个控制块的 `Data` 改变；有效记录 53 项，完整记录 54 项并含最终机器摘要。

本版的核心学习是：火箭发动机必须用实机喷焰方向验收——喷焰朝下，反作用力才朝上。工具朝向文字、几何位置和实机短点火三项必须同时记录；有冲突时以实机画面与真实运动为准。
