# Orbital Lancer V2 使用说明

> **已淘汰：** 实机截图确认 V2 虽然沿正确的 `+Z` 竖直，但 Booster 位于箭体顶端，整体上下关系错误。此文件仅用于追溯，不要把 V2 用作正式候选；请改用 V3。

## 应加载的文件

日常驾驶与轨道测试请加载：

`V2-轨道长矛-260904-212909.bsg`

带“原始结构”字样的文件是 MCP 原始版，只用于比赛原始构建证明，不应覆盖或手工修改。

## 键盘控制

| 按键 | 操作 |
| --- | --- |
| `↑` | 启动全部四台主推进器 |
| `↓` | 关闭全部四台主推进器 |
| `←` | 绕火箭纵轴向左修正 |
| `→` | 绕火箭纵轴向右修正 |
| 小键盘 `8` | 向前俯仰 |
| 小键盘 `2` | 向后俯仰 |
| 小键盘 `4` | 向左侧倾 |
| 小键盘 `6` | 向右侧倾 |

使用数字小键盘前请打开 Num Lock。反作用轮和 RCS 已开启自动制动，松开方向控制键后会主动抑制继续旋转。

## 起飞前检查

1. 火箭应沿游戏竖直方向站立，而不是像 A1 一样横躺。
2. 四个落地 Grip Pad 应在东、西、南、北四个方向形成稳定支撑。
3. 短按三组姿态键，观察火箭能否向相反方向成对响应并在松键后停止加速旋转。
4. 如果某一组控制方向与表格相反，只交换该组的按键映射；不要移动、旋转、缩放或删除方块。

## 起飞与入轨

1. 按一次 `↑`，确认四台主推进器同时启动。
2. 垂直离地并与地面拉开安全距离后按 `↓` 关机。
3. 用小键盘 `8/2` 缓慢压低或抬高箭体，把速度方向从径向上升转为沿行星表面的切向飞行。
4. 用 `←/→` 修正航向，用小键盘 `4/6` 消除侧倾；每次只短按，不要长时间满舵。
5. 箭体对准切向后再次按 `↑` 加速，达到可持续绕行速度后按 `↓` 关机。
6. 滑行阶段尽量少操作。轨迹开始持续围绕行星中心转动后，优先保持同一轨道平面。
7. 先确保连续完成三圈，再尝试用更短的加速段提高角速度分。

## 常见问题

- **按 `↑` 没反应：** 检查是否加载了主 `.bsg`，以及四台 Booster 的启动键是否仍为 `UpArrow`。
- **火箭持续自旋：** 立即按 `↓` 关主推进，松开所有方向键，让自动制动工作；再短按反向键消除剩余角速度。
- **某个方向完全不动：** 检查对应的一对反作用轮是否同时保留在机体上；不要只增加 RCS 推力。
- **按键方向反了：** 在 tuned 副本中交换对应的一对键值，这是允许的非几何调参；不要改变部件朝向。
- **起飞时卡地：** 确认四个 Grip Pad 没有被改成主动抓取或锁定状态，并使用四台主推进器同步起飞。
- **燃料快速耗尽：** 采用“加速—关机—滑行—短修正”的节奏，不要全程开启主推进。

## 比赛文件保护

- 保留原始 `.bsg`、有效 `.json` 和 `_full.json` 不变。
- tuned 版只允许调整游戏合法的非几何 `Data`、按键和力度。
- 不得修改方块位置、旋转、缩放、连接器端点或方块数量。
- 正式计分飞行后保存官方 Tracker 生成的轨迹 `.csv`，并确认结束时所有原始块仍连接 Starting Block。
