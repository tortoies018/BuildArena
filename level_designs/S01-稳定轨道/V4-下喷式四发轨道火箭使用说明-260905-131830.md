# V4 下喷式四发轨道火箭使用说明

## 加载文件

正式测试加载：`V4-下喷式四发轨道火箭-260905-131830.bsg`

带“原始结构”字样的 BSG 是 MCP 几何封存副本，控制 `Data` 为空，只用于追溯。

## 发动机方向检查

正确状态必须同时满足：

1. 圆形鼻头和两只大油箱在上。
2. 四只小燃料舱位于底部四周，并由四个升高支座承托。
3. 四台 Booster 吊在小燃料舱下方。
4. 点火后喷口火焰和烟雾朝地面向下喷，火箭受到的反作用力向上。
5. 四个 Grip Pad 比发动机本体更低，静止时发动机不能直接撞地。

V3 的错误是把 Booster 装在小油箱顶面：工具称其方向为 `straight up`，实机却显示火焰向上喷，实际推力把火箭向下压。V4 已将 Booster 改装到小油箱底面，工具方向为 `straight down`，这里应理解为喷口/喷焰朝下。

## 键盘控制

| 按键 | 功能 |
| --- | --- |
| `↑` | 同步启动四台主 Booster |
| `↓` | 同步关闭四台主 Booster |
| `← / →` | 左 / 右偏航 |
| 小键盘 `8 / 2` | 向前 / 向后俯仰 |
| 小键盘 `4 / 6` | 向左 / 向右侧倾 |

主推采用开关模式；按一次 `↑` 持续工作，按 `↓` 停止。使用小键盘前开启 Num Lock。反作用轮和 RCS 均开启自动制动。

## 首次实测顺序

1. 进入模拟后先不点火，确认四个 Grip Pad 同时承重，发动机没有接触地面。
2. 依次短按三组姿态键，确认每一对按键产生相反响应，松键后旋转能够受控减弱。
3. 极短按 `↑`，观察四股火焰是否同步向下喷；立即按 `↓`。
4. 只有当火箭明确离地上升时，才进行第二次较长点火。
5. 起飞后用小键盘 `8/2` 逐步转入切向飞行，`←/→` 修正航向，小键盘 `4/6` 消除侧倾。
6. 达到绕行速度后关机滑行，优先连续完成三圈，再优化时间。

## 故障处理

- 火焰仍向上：确认没有加载 V3；正确文件名以 `V4-下喷式` 开头。
- 按 `↑` 后火箭向下：立即按 `↓`，保存画面，不再长按；这说明游戏表现与当前判定仍不一致，应建立下一几何版本，不能只改按键。
- 某个姿态轴相反：只交换该轴成对控制器的 `bmt-left` / `bmt-right`，不要修改几何。
- 发动机触地：检查四个升高支座和 Grip Pad 是否完整；不要在原始结构副本上补块。
- 单台熄火：检查该吊舱 Fuel Line 及其小燃料舱连接。

当前已通过静态验证，仍需完成游戏内短点火、供油、方向、结构强度、三圈轨道和 Tracker CSV 验收。
