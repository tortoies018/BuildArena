# V3 底置四发轨道火箭学习摘要

> **版本状态：已淘汰。** 实机点火截图证明四台 Booster 的火焰向上，发动机方向相反。工具返回的 `straight up` 不能等同于火箭反作用力向上；V4 已把喷口改为向下。

V3 修正了两个连续错误：V1 把工具 `+Y` 当竖直轴而横躺；V2 改用正确的 `+Z` 竖直轴，却把 Booster 直接装在上部油箱顶面，使发动机处于箭体顶端。V3 保持 `+Z` 竖直，在 Starting Block 四周建立四个底部外伸供油吊舱，每个小油箱顶面安装一台 Booster。工具逐台确认四台发动机推力均朝 `+Z` 正上方；双大油箱和鼻锥位于发动机之上。

结构由 47 块组成：Starting Block 1、大油箱 2、小油箱 4、Booster 4、Double Wooden Block 4、Grip Pad 4、Reaction Steering Block 6、Steering Thruster 4、Fuel Line 4、Brace 12、Single Wooden Block 1、Armor Plate Round 1。四路供油、12 根支撑和四点落地提高了冗余度；三个正交控制轴各有成对反作用轮。

主文件只在 MCP 原始结构副本上写入合法 `Data`：方向键 `↑/↓` 启停主推，`←/→` 控制偏航，小键盘 `8/2` 控制俯仰，小键盘 `4/6` 控制侧倾。方块数量、GUID、位置、旋转、缩放和连接器端点不得改变。

静态验收结果为：原始版与主版均 47 块，身份与 Transform 差异为 0，仅 14 个控制块的 `Data` 改变。有效构建记录 49 项，完整记录 51 项并含最终机器摘要。本版仍需实机动态验收。若方向相反，只交换对应成对控制器的键值；若几何、供油或强度有问题，则保留 V3 并新建 V4，不得把手工几何改动伪装成 V3 调参。
